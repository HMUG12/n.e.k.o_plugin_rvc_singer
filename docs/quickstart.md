# RVC 歌声合成 — 快速开始

## 概述

RVC 歌声合成插件让 N.E.K.O 可以用 AI 训练好的声音演唱任意歌曲。

## 使用步骤

### 1. 启动 RVC Studio

RVC Studio 是独立的桌面程序，负责实际的人声分离和音色转换处理。

- 双击运行 RVC Studio 可执行文件
- 等待界面显示"就绪"状态
- 默认地址：`http://127.0.0.1:19877`

### 2. 在聊天中请求唱歌

直接对 N.E.K.O 说：
- "唱首歌"
- "来一首晴天"
- "唱一首 Fade"

N.E.K.O 会自动调用插件进行演唱。

### 3. 歌曲管理

- **搜索下载**：如果歌曲不在本地，插件会自动从网络搜索并下载音频
- **查看歌曲**：在面板中可以查看所有已上传的歌曲
- **上传歌曲**：作为最后手段，可以手动上传音频文件

## 配置说明

| 配置项 | 说明 | 默认值 |
|--------|------|--------|
| 主机地址 | RVC Studio 的 IP 地址 | 127.0.0.1 |
| 端口 | RVC Studio 的 HTTP 端口 | 19877 |
| RVC 根目录 | RVC 引擎所在目录 | `<RVC_ROOT_DIR>`（如 E:/rvc/1/RVC1006Nvidia） |
| 默认模型 | 默认使用的音色模型 | mi-test |
| 自动混音 | 是否自动合成背景音乐 | 是 |

## 常见问题

**Q: 提示"RVC Studio 未启动"？**
A: 请确保 RVC Studio 独立程序正在运行，且地址/端口配置正确。

**Q: 演唱失败？**
A: 检查歌曲音频文件是否存在于 RVC Studio 的 `neko/` 目录中。如不存在，使用搜索下载功能获取。

**Q: 处理很慢？**
A: RVC 人声分离和音色转换需要 GPU 计算资源，一首歌通常需要 1-5 分钟。
